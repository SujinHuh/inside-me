# 실제 AI 공급자 비교 — 텍스트 감정 탐색 1차 후보

- 조사일: 2026-08-24
- 관련 질문: Q-013
- 관련 요구사항: REQ-009, REQ-019, REQ-020, REQ-022
- 적용 상태: 사용자 결정 전 비교안, 실제 연결·계정·API 키·외부 전송 없음

> **현재 Gemini를 선택하거나 앱에 연결한 상태가 아니다.** Gemini는 OpenAI·Anthropic과 개인정보·비용을 비교하기 위해 조사한 대안 후보일 뿐이다. 현재 앱의 `AI와 더 살펴보기` 화면은 네트워크를 사용하지 않는 기기 내부 `DeterministicEmotionExplorer`를 호출한다. 실제 공급자는 Q-013에 대한 사용자 결정 뒤에만 연결한다.

## 비교 범위

Inside Me의 첫 실제 AI 기능은 사용자가 글·감정·욕구를 먼저 선택하고 `AI와 더 살펴보기`를 누른 경우에만 감정·욕구 보조 후보를 받는 짧은 텍스트 요청이다. 진단, 장기 기억, 웹 검색, 파일 업로드, 과거 일기 조회와 음성은 이번 공급자 선택에 포함하지 않는다.

비용보다 다음 순서를 우선한다.

1. 감정 기록이 모델 학습에 기본 사용되는지
2. 요청·응답이 얼마나 보존될 수 있는지와 무보존 설정의 실제 조건
3. 한국어 감정 표현을 단정·진단 없이 구조화된 계약으로 반환하는 품질
4. 서버에서 비밀 키를 보호하고 공급자를 교체할 수 있는지
5. 하루 한 번 개인 도그푸딩 비용

## 개인 도그푸딩 예상 비용

비교만을 위해 한 요청을 입력 1,000토큰·출력 300토큰, 하루 한 번·월 30회로 가정했다.

| 모델 | 1회 추정 | 월 30회 추정 | 월 60회 추정 |
|---|---:|---:|---:|
| OpenAI GPT-5.6 Luna | $0.000560 | $0.0168 | $0.0336 |
| OpenAI GPT-5.6 Terra | $0.005600 | $0.1680 | $0.3360 |
| Gemini 3.5 Flash-Lite 유료 | $0.001050 | $0.0315 | $0.0630 |

이 계산에서는 모델 비용 차이보다 민감정보 처리와 한국어 품질이 더 큰 선택 기준이다. 실제 사용량은 공급자 응답의 토큰 계측으로 다시 기록하고 월간 상한을 넘으면 자동 호출을 중단해야 한다.

## 제안하는 1차 선택

사용자 승인 전 상태는 `제안됨`이다.

- 텍스트 공급자: OpenAI Responses API
- 1차 비용 모델: `gpt-5.6-luna`
- 품질 비교 모델: `gpt-5.6-terra`
- 요청 방식: 서버의 foreground 단발 요청, `store: false`, 웹 검색·파일·대화 상태·background mode 미사용
- 월간 도그푸딩 모델 비용 상한: **$3 제안**. 서버·세금은 별도이며 사용자 승인 후 확정한다.
- 품질 게이트: 실제 일기 대신 합성 한국어 상황 20개 이상으로 두 모델을 같은 출력 계약에서 비교한다. 비단정성, 진단 금지, 후보 다양성, 이유의 자연스러움과 잘못된 스키마 비율을 기록한다.
- 승격 기준: Luna가 안전·계약·한국어 기준을 통과하면 기본으로 사용한다. 차이가 반복적으로 크면 Terra를 기본으로 바꾸되 비용 상한은 유지한다.

선택 이유는 가장 좋은 모델이라고 단정해서가 아니다. 첫 텍스트 기능과 후속 전사·음성 기능을 한 공급자 계정에서 검증할 수 있고, 현재 공급자 독립 계약 뒤에 어댑터 하나를 추가해 되돌리기 쉽기 때문이다.

## 실제 연결 전에 고정할 서버 경계

- Expo 앱이나 `EXPO_PUBLIC_*`에 API 키를 넣지 않는다.
- 사용자 승인 뒤에만 `server/`를 만들고, 앱은 Inside Me 서버의 단일 감정 후보 endpoint만 호출한다.
- Expo 앱의 HTTP 어댑터가 기존 `ExternalEmotionExplorerTransport` 포트를 구현해 Inside Me 서버 endpoint를 호출한다.
- 서버는 앱 계약과 분리된 provider port·adapter로 OpenAI 요청·응답을 변환한다. 앱과 서버 양쪽에서 각 경계의 최소 schema를 검증한다.
- 요청에는 IMP-201에서 허용한 이야기, 비민감 요청 ID, 검증된 카탈로그 감정·욕구 ID만 포함한다. 날짜, 기록 ID, 기기 정보, 과거 기록, 직접 추가 표현과 사용자 식별자는 제외한다.
- 공급자 응답 자유문을 그대로 저장하지 않고 기존 런타임 parser와 `reasonCode` 매핑을 통과한 후보만 앱에 전달한다.
- 서버·호스팅 로그에 요청 본문, 응답 본문, 일기, 감정과 전사를 남기지 않는다. 상태 코드, 지연, 토큰 수와 비민감 요청 ID만 허용한다.
- 자동 재시도는 하지 않는다. 사용자가 화면에서 다시 시도할 때만 새 요청을 보내 중복 비용과 원치 않는 반복 전송을 막는다.
- 타임아웃·취소 뒤 사용자 글과 선택은 기기에 유지한다.

## 사용자에게 필요한 결정

1. 기본 30일 이내 안전 모니터링 로그 가능성을 감수하고 개인 도그푸딩을 진행할지
2. 1차 공급자로 OpenAI를 사용하고 Luna·Terra 합성 평가를 진행할지
3. 월간 모델 비용 상한 $3를 허용할지
4. 계정·API 키·서버 배포 준비까지 진행할지, 먼저 로컬 mock 서버까지만 만들지

어느 항목도 사용자가 명시적으로 승인하기 전에는 계정 생성, 결제, 키 입력, 서버 배포 또는 실제 일기 전송을 하지 않는다.
