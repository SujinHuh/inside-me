## 이미지에서 확인한 구조

- 감정 어휘를 욕구가 충족됐을 때와 충족되지 않았을 때 연결되기 쉬운 표현으로 나눈다.
- 욕구 어휘를 자율성, 신체·생존, 관계, 놀이, 의미, 진실성, 평화, 자기구현처럼 큰 주제로 묶는다.
- 한 화면에 많은 어휘를 보여 주어 사용자가 AI의 해석 전에 자신의 표현을 직접 찾아볼 수 있게 한다.

## Inside Me에 적용할 원칙

- 이미지를 그대로 선택 화면으로 쓰지 않고 구조화된 어휘 데이터로 옮긴다.
- 모바일에서는 검색, 주제별 필터, 세로 스크롤과 선택 가능한 텍스트 항목을 제공한다.
- `욕구 충족과 연결된 느낌`, `욕구 미충족과 연결된 느낌`은 탐색을 돕는 필터일 뿐 감정의 좋고 나쁨이나 객관적 원인으로 저장하지 않는다.
- 목록에 없는 표현을 직접 추가할 수 있고 `아직 모르겠어요`, `AI 도움 받기`로 넘어갈 수 있게 한다.
- 자유 글, 자유 음성, AI 턴 대화가 서로 다른 입력을 끝낸 뒤 같은 자기 탐색 화면과 데이터 계약을 사용한다.
- 사용자가 먼저 고른 항목, AI가 나중에 제안한 항목과 최종 확정 항목을 데이터에서 구분한다.

## UI 권고안

첫 화면에 전체 어휘를 작은 글씨로 한꺼번에 넣지 않는다.

1. 기본 진입은 `전체 감정 보기`와 검색으로 두고, 편안함·활력 쪽과 불편함·긴장 쪽은 필수 관문이 아닌 선택 필터로 제공한다.
2. `여러 느낌이 섞여 있어요`, `어느 쪽도 아니에요`, `아직 모르겠어요`와 직접 입력을 동등한 경로로 둔다. 필터를 선택해도 반대편 어휘를 숨기지 않고 복수 선택을 허용한다.
3. 어휘는 검색 가능하고 기본으로 접힌 주제별 세로 목록 또는 여러 줄 선택 항목으로 보여 준다.
4. 선택한 감정과 가까운 표현을 나란히 비교할 수 있게 한다.
5. 감정 선택 뒤 욕구 주제와 세부 욕구를 같은 방식으로 탐색한다.
6. 마지막에만 `AI와 더 살펴보기`를 선택적으로 제공한다.

고정 이미지는 `한눈에 보기` 보조 자료가 될 수 있지만 기본 선택 UI로 사용하지 않는다. 이미지 속 작은 글자는 접근성이 낮고 선택 상태, 검색, 스크린 리더, 어휘 수정과 직접 추가를 지원하기 어렵기 때문이다.

## 검토가 필요한 점

- 일부 표현은 감정이라기보다 생각, 평가나 상태로 해석될 수 있으므로 정답 분류로 취급하지 않는다.
- 같은 감정도 여러 욕구와 연결될 수 있으므로 감정과 욕구를 일대일로 자동 연결하지 않는다.
- 이미지의 모든 단어를 그대로 채택하기 전에 중복, 오탈자, 일상적인 한국어 이해도와 심리적 안전을 검토한다.
- 긴 목록이 선택 피로를 만들지 않는지 Android 실제 크기로 검증한다.
