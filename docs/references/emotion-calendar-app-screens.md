# 감정 선택·달력 앱 화면 참고 노트

- 제공일: 2026-08-23
- 제공자: 사용자
- 용도: Inside Me 감정 선택과 월간 달력의 정보 구조·표정 표현 연구
- 제한: 다른 앱의 화면을 그대로 복제하거나 이미지·캐릭터를 제품 자산으로 재사용하지 않는다. 출처와 재배포 허용 범위가 확인되지 않은 원본 화면은 공개 저장소에 복사하지 않고, 구조적 장점과 주의점만 추출해 Inside Me 전용 시각 체계로 다시 설계한다.

## 제공 화면에서 확인한 구조

- 여러 색과 얼굴 형태의 감정을 3열 격자로 비교하는 선택 화면
- 날짜 셀마다 작은 표정을 배치해 한 달의 기록을 훑는 월간 화면
- 같은 다섯 단계 기분을 서로 다른 캐릭터 스타일로 비교하는 화면
- 큰 감정 캐릭터와 날짜별 작은 캐릭터를 함께 사용한 달력 화면

## 참고할 디자인 DNA

- 작은 달력 셀에서도 눈·입·눈썹·볼·눈물·땀 같은 형태 차이로 표정을 구별한다.
- 선택 화면에서는 여러 표정을 한눈에 비교하고, 달력에서는 같은 시각 언어를 더 작게 재사용한다.
- 기록이 있는 날짜와 없는 날짜가 즉시 구분되지만 빈 날짜를 실패처럼 표현하지 않는다.
- 얼굴 실루엣과 색을 조금씩 달리해 한 달의 리듬을 빠르게 훑을 수 있다.
- 달력의 표정을 누르면 해당 날짜의 기록으로 이어지는 구조가 자연스럽다.

## Inside Me에서 다르게 적용할 점

- `훌륭한·나쁜·괜찮아·끔찍한` 같은 평가형 5단계를 감정 이름으로 사용하지 않는다.
- 좋음·나쁨을 색 하나로 판정하지 않고 `감사한`, `서운한`, `막막한`, `억울한`처럼 사용자가 고른 구체적인 대표 감정을 중심으로 표현한다.
- 사용자는 감정을 여러 개 선택하고 그중 달력에서 먼저 기억할 대표 감정 하나를 직접 고른다. 추가 감정은 날짜 셀의 보조 표시와 상세 화면에서 보존한다.
- 색상만으로 의미를 전달하지 않는다. 전용 얼굴 형태, 정확한 감정 이름과 접근성 레이블을 함께 제공한다.
- 현재 11개 감정 주제는 표정 설계와 탐색을 시작하는 묶음일 뿐 최종 감정 수를 제한하는 목록이 아니다. 구조화 어휘 확장과 직접 추가를 허용한다.
- Windows Classic의 격자·테두리·제목 표시줄은 유지하되 표정은 따뜻하고 차분하게 설계해 감정 기록이 장난감이나 점수표처럼 보이지 않게 한다.

## 구현·검수 질문

- 40~48dp 안에서도 얼굴 형태가 색 없이 구별되는가?
- 대표 감정 이름을 함께 읽었을 때 얼굴의 의미가 오해되지 않는가?
- 추가 감정이 있다는 표시가 달력 셀을 복잡하게 만들지 않는가?
- 비슷한 감정과 강도 차이를 얼굴만으로 억지로 구분하지 않고 상세 정보로 보완하는가?
- 큰 글자와 스크린 리더에서 날짜, 대표 감정, 추가 감정 수를 이해할 수 있는가?
