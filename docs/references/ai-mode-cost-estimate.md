# 개인 도그푸딩 AI 3모드 비용 추정과 측정 계획

- 조사일: 2026-08-24
- 적용 대상: 개발자 본인 한 명의 개인 도그푸딩
- 상태: 0단계 오프라인 계산기·합성 예산 테스트 자동 검증·독립 검수 완료, 실제 API 연결·결제·과금 테스트 없음
- 관련 요구사항: REQ-002, REQ-003, REQ-010, REQ-012, REQ-014, REQ-017
- 관련 질문: Q-013

## 먼저 구분할 세 가지 경험

1. **텍스트**: 글을 보내고 AI의 답변도 글로 읽는다.
2. **자유 음성 기록**: 하루 이야기를 한 번에 말하고 전사한 뒤 AI 결과는 글로 확인한다. 음성 출력은 없다.
3. **음성 핑퐁**: 사용자가 말하면 AI가 음성으로 되묻는 과정을 3~6턴 이어 간다. 기본 세션은 REQ-017에 따라 5분으로 가정한다.

여기서 말하는 비용은 ChatGPT나 Codex 구독료가 아니라 Inside Me 서버가 OpenAI API를 호출할 때 발생하는 별도 사용량 비용이다. 현재는 실제 API를 연결하지 않았으므로 과금은 0이다.

## 공통 계산 가정

- 한 사람, 하루 1회, 월 30회
- 텍스트 1회: 입력 1,000토큰·출력 300토큰
- 자유 음성 1회: 사용자 음성 5분을 전사하고 위 텍스트 요청 1회 수행
- 음성 핑퐁 1회: 총 5분 중 사용자와 AI가 각각 2.5분 말함
- 턴형 음성 핑퐁의 텍스트 합계: 세션당 입력 3,000토큰·출력 1,000토큰. 실제 계산 입력은 장문 배수 기준을 요청별로 적용할 수 있도록 각 턴의 요청별 토큰으로 나눈다.
- 턴형 음성 출력 길이 가정: 한국어 300자/분. 공식 과금 기준이 아니라 실제 계측으로 교체할 제품 가정
- 환율, 세금, 서버·네트워크 비용, 실패 재시도는 제외
- 가격과 모델은 조사일 기준이며 연결 직전에 다시 확인
- Luna·Terra는 입력이 272K 토큰을 초과하면 해당 요청 전체 입력 2배·출력 1.5배 단가를 적용한다. 현재 1,000·3,000토큰 시나리오는 이 기준보다 작다.

## 1. 텍스트

| 모델 | 1회 | 월 30회 |
|---|---:|---:|
| GPT-5.6 Luna | $0.000560 | $0.0168 |
| GPT-5.6 Terra | $0.005600 | $0.1680 |

따라서 혼자 하루 한 번 쓰는 텍스트 감정 탐색의 모델 비용은 현재 가정에서 **월 약 $0.02~$0.17**다. 실제 출력이 길거나 추론 토큰이 늘면 증가한다.

## 2. 자유 음성 기록 후 텍스트 결과

`gpt-transcribe`의 공식 추정 단가 $0.0045/분을 사용한다.

- 월 음성: 5분 × 30회 = 150분
- 월 전사비: 150분 × $0.0045 = $0.675
- Luna 포함: $0.675 + $0.0168 = **$0.6918**
- Terra 포함: $0.675 + $0.1680 = **$0.8430**

따라서 매일 5분씩 한 번에 말하고 결과를 글로 받으면 **월 약 $0.70~$0.85**로 추정한다. 원본 오디오는 전사 성공 후 삭제하고, 전사 정확도는 합성 한국어 음성으로 별도 평가해야 한다.

## 3. 음성 핑퐁

### 3-1. 저비용 우선: 전사 → 텍스트 AI → 음성 합성

각 턴을 `전사 → Luna 또는 Terra → TTS`로 이어 붙인다. 요청형 API는 구현과 비용 계측이 단순하지만, 자연스러운 실시간 대화보다 턴 사이 대기 시간이 길 수 있다.

사용자 음성 2.5분/일이면 전사비는 월 $0.3375다. `tts-1`의 공식 단가 $15/백만 문자를 사용하고 AI가 300자/분으로 2.5분씩 말한다고 가정하면, 월 22,500자 음성 합성비도 $0.3375다. 세션당 입력 3,000·출력 1,000텍스트 토큰을 더하면 Luna는 월 $0.054, Terra는 $0.54다.

- Luna 합계: $0.3375 + $0.3375 + $0.054 = **$0.729**
- Terra 합계: $0.3375 + $0.3375 + $0.54 = **$1.215**

따라서 초기 계획 범위는 **월 약 $0.73~$1.22**다. 한국어 300자/분은 공식 정액 기준이 아니라 소액 합성 테스트에서 실제 생성 문자 수로 교체할 제품 가정이다.

### 3-2. 자연스러운 저지연 우선: Realtime 음성 대화

`gpt-realtime-2.1-mini`의 오디오 단가는 입력 $10/백만 토큰, 출력 $20/백만 토큰이다. 공식 비용 가이드에 따르면 사용자 오디오는 100ms당 1토큰, AI 오디오는 50ms당 1토큰이다.

5분 세션을 사용자 2.5분·AI 2.5분으로 가정하면:

- 월 사용자 음성: 75분 × 600토큰/분 = 45,000 입력 오디오 토큰 → **$0.45**
- 월 AI 음성: 75분 × 1,200토큰/분 = 90,000 출력 오디오 토큰 → **$1.80**
- 오디오 기본 합계: **월 $2.25**

Realtime은 매 응답에서 이전 대화가 다음 입력에 포함돼 뒤쪽 턴이 더 비싸질 수 있다. 캐시가 일부 비용을 낮추지만 지시문·텍스트·특수 토큰과 턴 수가 달라지므로, **5분 매일 사용은 월 $3~$5 계획 범위**로 잡고 실제 계측 전 확정하지 않는다. 10분씩 매일 사용하면 오디오 기본 합계만 약 $4.50이므로 계획 범위는 월 $6~$8로 높인다.

## 비교 요약

| 사용 방식 | 하루 사용 가정 | 월 예상 또는 계획 범위 | 현재 판단 |
|---|---:|---:|---|
| 텍스트 | 1회 | $0.02~$0.17 | 가장 먼저 실제 품질·비용 측정 |
| 자유 음성 → 텍스트 결과 | 음성 5분 | $0.70~$0.85 | 전사 품질 확인 뒤 추가 |
| 턴형 음성 핑퐁 | 총 5분 | $0.73~$1.22 가설 | 비용·복구가 단순해 첫 음성 대화 후보 |
| Realtime 음성 핑퐁 | 총 5분 | $3~$5 계획 범위 | 자연스러움이 실제로 필요한지 비교 뒤 선택 |

서버 호스팅 비용은 포함하지 않았다. 개인 도그푸딩에서는 로컬 중계 서버로 먼저 검증할 수 있지만, 휴대폰 외부 사용을 위한 배포 서버 비용은 별도 결정이다.

## 비용 측정 테스트 제안

실제 일기나 실제 감정 음성을 사용하지 않고 합성 한국어 자료만 사용한다.

### 0단계 — 무료 산식 테스트

- 모델 단가, 텍스트 토큰, 음성 분, Realtime 오디오 토큰을 입력하면 예상 USD를 계산하는 순수 함수와 단위 테스트를 만든다.
- 가격표 버전과 조사일을 입력 데이터로 분리해 단가 변경 시 계산 로직을 바꾸지 않는다.
- 월 사용 횟수와 1·3·5·10분 시나리오 계산 결과를 만들고 이 문서의 표·산식과 대조한다.
- 구현 상태: `src/core/ai-costs/`에서 비용 계산과 실제 호출 없는 단일 요청 예산 예약·정산·취소·후속 차단을 구현했다. 자동 검증과 독립 검수에서 확인된 오류 0개이며 앱 화면이나 실제 공급자에 연결하지 않았다.

### 1단계 — 사용자 승인 뒤 $1 예산 목표의 합성 계측

- 텍스트: 합성 상황 20건을 Luna·Terra에 동일하게 요청
- 자유 음성: 합성 한국어 음성 1·3·5분 파일을 전사
- 턴형 음성: 합성 전사·응답·TTS 1·3·5분 상당 흐름
- Realtime: 합성 대본으로 1·3·5분 세션
- 동시에 하나의 요청만 허용한다. 다음 시나리오의 보수적 최대 예상비를 서버에서 먼저 예약하고, 남은 승인 예산보다 크면 요청을 보내지 않는다.
- 응답 usage와 조직 Costs API가 예상보다 크면 이후 호출을 즉시 중단한다. 정확한 사용량은 응답 뒤에 확정되므로 마지막 요청으로 $1을 소액 초과할 가능성까지 사용자 승인 범위에 명시한다.

계측에는 모델명, 요청·세션 ID, 입력·출력 텍스트 토큰 수, 캐시 토큰 수, 입력·출력 오디오 토큰 수, 전사 분, 턴 수, 지연, 성공·안전 오류 코드와 계산 USD만 남긴다. 요청 본문, 응답 본문, 음성, 전사와 감정 선택은 비용 로그에 남기지 않는다. 요청별 계산 합계는 OpenAI 조직 Costs API 또는 Usage Dashboard의 프로젝트 비용과 대조한다.

### 통과 기준

- 공식 단가 계산과 공급자 usage 필드로 계산한 값의 차이를 설명할 수 있다.
- 같은 합성 시나리오를 반복했을 때 비용 범위가 재현된다.
- 취소·타임아웃·재시도에서 중복 과금 요청을 만들지 않는다.
- 다음 요청의 보수적 최대 예상비가 남은 승인 예산 또는 세션별 예산보다 크면 호출하지 않고, 응답 usage 확인 뒤 후속 호출을 중단한다.
- 비용이 낮아도 한국어 전사, 비단정성, 응답 자연스러움과 개인정보 기준을 통과하지 못하면 채택하지 않는다.

## 권고

비용만 보면 `텍스트 → 자유 음성 → 턴형 음성 → Realtime` 순서로 확장하는 것이 안전하다. 먼저 무료 계산기를 구현하고, 사용자가 보존 조건·OpenAI 사용·$1 예산 목표와 마지막 요청의 소액 초과 가능성을 명시적으로 승인한 뒤 실제 계측한다. Realtime은 음성 핑퐁의 지연과 끼어들기 경험이 턴형 방식보다 분명히 낫다는 실기기 결과가 있을 때만 선택한다.
