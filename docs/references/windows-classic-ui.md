## 관찰한 디자인 DNA

- 선명한 파란색 제목 표시줄과 밝은 회색 작업 영역의 강한 구분
- 둥글지 않은 직사각형 창과 버튼
- 밝은 위·왼쪽 테두리와 어두운 아래·오른쪽 테두리로 만든 돌출 버튼
- 반대 방향의 테두리로 안쪽에 들어간 입력·표시 영역
- 좁은 색상 팔레트 안에서 파랑과 빨강을 기능 구분에 제한적으로 사용
- 정렬이 명확한 촘촘한 격자와 물리적으로 눌리는 느낌
- 픽셀 또는 비트맵을 연상시키는 제목과 레이블
- 장식보다 상태와 기능을 직접 보여주는 도구 같은 인상

## Inside Me에서 가져올 것

- 화면 또는 주요 패널의 얇은 고전 창 테두리
- 눌림 상태가 분명한 입체 버튼과 선택된 탭
- 텍스트 입력, 전사 결과와 감정 요약을 안쪽으로 들어간 패널로 표현
- 기록 모드, 달력 날짜와 감정 선택에서 정돈된 격자 리듬 사용
- 파란 제목 표시줄의 인상을 브랜드 색으로 재해석
- 둥근 카드가 반복되는 일반적인 AI 앱 대신 각진 패널과 명시적인 구분선 사용

## 그대로 복제하지 않을 것

- 작은 픽셀 글꼴을 긴 한글 본문에 사용하지 않는다.
- 계산기의 높은 정보 밀도와 작은 버튼 간격을 모바일에 그대로 옮기지 않는다.
- 닫기·최소화·최대화처럼 실제 OS 기능으로 오해할 장식 버튼을 의미 없이 사용하지 않는다.
- 회색 일색으로 감정 표현이 차갑거나 사무적으로 느껴지게 만들지 않는다.
- 빨강과 파랑을 원본처럼 장식적으로 쓰지 않고 의미가 있을 때만 사용한다.
- 모든 컴포넌트를 같은 입체 상자로 만들어 정보 위계를 평평하게 만들지 않는다.

## 현대화 기준

- 터치 대상은 충분한 크기와 간격을 확보한다.
- 본문은 가독성 좋은 한글 글꼴을 사용하고 픽셀 감각은 제목·숫자·짧은 레이블에 제한한다.
- 포커스, 눌림, 녹음 중, 처리 중, 오류와 비활성 상태를 색상 하나에만 의존하지 않는다.
- 대비, 스크린 리더 레이블, 키보드 조작과 모션 감소 설정을 지원한다.
- 부드러운 아이보리·회색 또는 저채도 색을 검토해 감정 기록의 따뜻함을 보완한다.

## 화면별 적용 후보

- 홈: 고전 프로그램 실행 창처럼 세 가지 기록 방식 버튼을 명확히 배치
- 글 기록: 안으로 들어간 큰 텍스트 영역과 물리적인 저장·이어가기 버튼
- 음성 기록: 녹음 버튼이 실제로 눌린 상태를 보이고 상태 표시줄에 시간을 표시
- AI 턴 대화: 말풍선 카드의 반복보다 대화 기록 패널과 현재 질문 패널을 구분
- 달력: 각 날짜를 작은 입체 셀로 만들되 기록 유무와 감정 표정의 가독성을 우선
- 날짜 상세: 고전 속성 창처럼 상황, 감정, 욕구와 다음 행동을 탭 또는 구획으로 정리

- 버튼의 입체감이 모바일에서 실제 상태를 이해하는 데 도움이 되는가?

- 세련됨을 일부러 피한 화면이 아니라 의도적으로 설계된 화면처럼 보이는가?
