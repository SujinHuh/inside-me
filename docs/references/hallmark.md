## 무엇인가

Hallmark는 Claude Code, Cursor와 Codex용 anti-AI-slop 디자인 스킬이다. 색상만 바꾼 동일 템플릿이 아니라 제품 맥락에 맞는 구조, 글꼴, 색상, 컴포넌트와 상호작용을 선택하도록 지침과 검수 목록을 제공한다.

원본이 제공하는 대표 흐름은 다음과 같다.

- `design`: 새 화면을 설계하고 구현한다.
- `audit`: 현재 화면을 읽고 문제의 우선순위를 보고하며 코드는 수정하지 않는다.
- `redesign`: 기존 기능·라우트·정보 구조를 보존하면서 필요한 시각·상호작용 층을 다시 설계한다.
- `study`: 사용자가 제공한 화면이나 URL에서 구조, 글꼴 역할, 색상 기준과 컴포넌트 성격을 추출한다. 픽셀 복제는 하지 않는다.

## Inside Me 적용 우선순위

1. 사용자가 직접 제공한 요구와 시각 참고자료
2. 감정 기록에 집중할 수 있는 차분함, 심리적 안전과 접근성
3. 확정된 Inside Me 디자인 토큰과 컴포넌트 규칙
4. Hallmark의 현재 화면에 관련된 원칙

Hallmark는 참고 기준이다. 사용자 취향이나 제품 목적과 충돌하면 프로젝트 기준을 우선하며 차이를 결정 로그에 남긴다.

## 채택할 원칙

### 제품 고유성

- 화면을 다른 AI 채팅 또는 SaaS 제품에도 그대로 붙일 수 있는 일반 템플릿으로 만들지 않는다.
- 장식에는 감정 탐색, 하루 기록, 개인 다이어리라는 맥락상 이유가 있어야 한다.
- 모든 화면을 동일한 카드 묶음으로 만들지 않고 정보의 역할에 따라 구조와 리듬을 정한다.
- 실제 사용자 문구와 데이터만 사용하며 통계, 후기, 효능을 꾸며내지 않는다.

### 시각 체계

- 색상, 글꼴, 간격, 테두리, 그림자와 움직임을 이름이 있는 토큰으로 먼저 정의한다.
- 이유 없는 카드 안 카드, 균일한 3열 카드, 보라색·파란색 장식 그라데이션, 떠다니는 구체와 문맥 없는 일러스트를 기본값으로 사용하지 않는다.
- 하나의 기능 아이콘 체계를 유지한다. 달력의 얼굴 표정은 운영체제 이모지에 의존하지 않고 일관된 전용 세트로 설계한다.
- 한글 가독성을 먼저 확인하고 제목용과 본문용 글꼴의 역할을 의도적으로 정한다. Hallmark의 영문 글꼴 금지 목록을 한글 UI에 기계적으로 적용하지 않는다.
- 레트로 표현은 색을 바랜 종이, 얇은 창 테두리, 눌리는 버튼과 제한된 픽셀 감각처럼 선택적으로 사용하고 모든 요소를 XP 모사로 만들지 않는다.

### 상호작용과 접근성

- 버튼과 입력 요소는 기본, 눌림, 포커스, 비활성, 로딩, 오류와 성공 상태 중 해당하는 상태를 명시적으로 설계한다.
- 키보드 포커스는 즉시 보이고, 포커스와 터치 대상의 대비와 크기를 확인한다.
- 움직임마다 모션 감소 대안을 제공하고 상태 전달을 애니메이션에만 의존하지 않는다.
- Android 작은 화면과 320px 이상의 웹 화면에서 가로 넘침이 없는지 확인한다.
- 보이는 결과만으로 성공을 알 수 있는 작업에 불필요한 축하 팝업을 반복하지 않는다.

## 그대로 적용하지 않을 원칙

- hero, navigation, footer와 랜딩 페이지 macrostructure 규칙은 모바일 감정일기 화면에 직접 적용하지 않는다.
- 페이지마다 구조를 의도적으로 바꾸라는 다양성 규칙보다 한 앱 안의 일관된 디자인 시스템을 우선한다.
- 특정 글꼴, 색상 면적 비율, 테마와 CSS 구현 방식은 React Native·한글·접근성 조건에 맞게 다시 판단한다.
- Hallmark의 주관적인 취향을 기능 이해도나 익숙한 모바일 조작 관례보다 앞세우지 않는다.

## Inside Me UI 작업 흐름

1. 사용자가 가져온 화면을 보고 좋아하는 점과 싫어하는 점을 분리한다.
2. 구조, 글꼴 역할, 색상 기준, 표정 아이콘 성격, 테두리와 움직임을 `study` 관점으로 추출한다.
3. “부드러운 XP/90년대 개인 다이어리”, “절제된 레트로”, “현대적이지만 비정형적” 목업을 작게 비교한다.
4. 선택한 방향을 프로젝트 디자인 토큰과 컴포넌트 규칙으로 고정한다.
5. 구현 전후에 Hallmark 원칙을 적용한 `audit`을 수행하되 코드 수정은 별도 요청이나 구현 작업 범위에서 한다.
6. Android 실제 기기에서 가독성, 터치, 키보드, 음성 상태와 감정 집중도를 확인한다.

## 설치에 관한 메모

원본은 개인 범위 `~/.codex/skills/hallmark/` 또는 프로젝트 범위 `.codex/skills/hallmark/` 설치를 지원한다고 안내한다. 현재는 설치하지 않고 공개 원본을 참고해 프로젝트에 필요한 기준만 문서화했다. 설치 여부는 Q-021에서 관리한다.
