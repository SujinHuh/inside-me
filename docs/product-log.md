## 과거 기록을 참고할 때

2026-08-18부터 2026-09-05까지의 장문 기록 160개는 [과거 제품 로그](archive/product-log-legacy-20260818-20260905.md)에 보존한다. 과거 LOG 번호의 상세 맥락이나 당시 사용자 발화가 필요한 경우에만 보관본에서 해당 ID를 검색한다. 평소에는 현재 요구사항과 결정 문서를 먼저 읽는다.

2026-09-07 이후 신규 기록은 이 파일 아래의 해당 월에만 추가한다. 보관본에는 새 기록을 추가하지 않는다.

작성 방법은 [제품 로그 작성 규칙](development-workflow.md#제품-로그-작성-규칙)을 따른다.
